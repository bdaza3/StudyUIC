# StudyUIC
StudyUIC is a web and mobile application in development that allows UIC students to freely view a customized map of campus that displays study spots, as well as study sessions that other students can create for others to join. 
Students can create a beacon on the interactive map, where students can attend or participate in to study in group meetups. 
StudyUIC also provides students with a list of study spots that contain detailed information on the crowdedness, noise, outlet availability, and other factors that students may find useful when searching for a place to work or study.
